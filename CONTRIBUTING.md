# Contributing to 360YA Explorer Community

Thank you for helping improve this free and open-source project. Contributions in Spanish or English are welcome.

## Before contributing

- Check existing [issues](https://github.com/EL-CHANGO-v4/360ya-explorer-community/issues) before opening a new one.
- For bugs, include the Explorer version, operating system, steps to reproduce, expected result and actual result.
- Never share passwords, SSH keys, session tokens, private server details or `.env` files.
- Debian 13 AMD64 with Python 3.13 is the currently tested platform. Please label results on other platforms as experimental.

## Code contributions

1. Fork the repository and create a focused branch.
2. Keep changes small and avoid unrelated refactoring.
3. Follow the installation instructions in [README.md](README.md).
4. Run `bash install.sh --test` after installing dependencies and report the results.
5. Open a Pull Request explaining what changed, why and how you tested it.

Please do not commit runtime data, credentials, local environment files or backups.

## Español

Se aceptan reportes, propuestas, traducciones y contribuciones en español. Antes de publicar un error, verificá que no exista otro Issue similar. Para colaborar, creá un fork, prepará un cambio acotado y enviá un Pull Request con los resultados de las pruebas.
